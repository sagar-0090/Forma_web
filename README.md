# VYRA — Premium Fitness Website

A frontend-only React + Vite gym website with:
- Minimal ivory / sage / terracotta visual system
- Responsive multi-page routing
- Animated floating dumbbells in the hero and quote sections
- Large editorial typography and gym photography
- Home, Programs, Coaches, Membership and Contact pages
- Working client-side enquiry form state
- No backend required

## Run locally

1. Install Node.js (18+ recommended).
2. Open this folder in Terminal.
3. Run:

```bash
npm install
npm run dev
```

4. Open the local URL printed by Vite, usually:
http://localhost:5173

## Production build

```bash
npm run build
npm run preview
```

Photos are loaded from Unsplash URLs, so an internet connection is recommended while developing.
